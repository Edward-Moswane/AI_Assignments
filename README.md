# Edward Moswane Assignment 08 Supervised Learning Classification 
I used the Breast Cancer Wisconsin (Diagnostic) dataset for this 
assignment.  
I started by loading and inspected the dataset, checked for missing 
values, duplicate records, and zero values, then separated the features 
and target variable. I performed exploratory data analysis (EDA) using 
class distributions, histograms, and a correlation heatmap for 
visualizations. I split the data into training and testing sets using an 
80/20. 
I then trained and evaluated two classification models, K-Nearest 
Neighbors (KNN) and Logistic Regression, using accuracy, precision, 
recall, F1-score, ROC-AUC, confusion matrices, and ROC curves as 
required.  
After carefully comparing the results, I concluded that Logistic 
Regression performed best.

# Edward Moswane Assignment 09 Supervised Learning Classification 
I have selected Mall Customers dataset for assignment_09 to perform 
unsupervised learning for customer segmentation.  
Using google Colab, I preprocess the data by checking for missing values 
and duplicates records, standardizing numerical features, and then apply 
K-Means and Hierarchical Clustering to identify customer groups.  
Elbow Method and Silhouette Score were used to evaluate the clusters, 
while PCA was used for dimensionality reduction and visualization. 
To run the code successfully, open the assignment09.ipynb notebook in 
Google Colab, run the cells in order from top to bottom, and review the 
generated tables, graphs, clustering results, and analysis.
